# AENural fonts

Sora and Inter are bundled locally with their original SIL Open Font License 1.1 files. Retrieved from the official Google Fonts repository on 2026-10-08. No visitor-side requests to Google Fonts are made.

- Sora: https://github.com/google/fonts/tree/main/ofl/sora (Sora[wght].ttf)
- Inter: https://github.com/google/fonts/tree/main/ofl/inter (Inter[opsz,wght].ttf)

The included OFL texts are unmodified upstream license files.
